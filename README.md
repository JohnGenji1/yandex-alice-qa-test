 Тестовое задание на позицию QA Engineer (Яндекс Алиса)

В данном репозитории представлено решение практического тестового задания по проверке голосового помощника Алиса (компоненты: Диалоги, Погода, Музыка, Картинки, Монетка, Игры).

  1. Результаты прогона тест-кейсов (Test Run)

*Компонент «Диалоги» (Тест-кейс 1):** ❌ Fail — На Шаге 2 в ответе отсутствует день недели и дата для г. Владивосток (нарушение спецификации).
Компонент «Погода» (Тест-кейс 2):** ❌ Fail — На Шаге 1 и Шаге 3 заголовок карточки содержит некорректный текст «Сегодня в...» вместо регламентированного в ТЗ «Сейчас в...».
Компонент «Музыка» (Тест-кейс 3):** ❌ Fail — На Шаге 1 получен полный отказ воспроизведения по голосовой команде, основная функция заблокирована.
Компонент «Картинки» (Тест-кейс 4):** ❌ Fail — На Шаге 3 под колдунщиком картинок отсутствует обязательная кнопка/ссылка «ещё картинки» для перехода в поисковую выдачу.
Компонент «Монетка» (Тест-кейс 5):** ❌ Fail — На Шаге 1 отсутствует звуковой эффект звона монеты; текстовый ответ «Подбросила!» не соответствует требованию ТЗ («Готово»).
Компонент «Игры — Угадай песню» (Тест-кейс 6): ❌ Fail — В интерактивной карточке ответа на шагах 2 и 3 отсутствуют обязательные элементы UI (кнопки оценки «Лайк» и «Дизлайк»).

---

  2. Оформление критического дефекта (Баг-репорт)

 ID: 01
 Summary (Заголовок):** Отсутствие запуска аудио и элементов управления при голосовом запросе «Включи музыку» в чате Алисы AI.
 Severity (Серьезность):** Blocker.
 Priority (Приоритет):** High.
 Environment (Окружение):** Realme C51, Android 15. Сборка приложения «Яндекс — с Алисой AI» v26.83 (260803173) от 10.09.2026.
   Preconditions (Предусловия):**
  1. Выполнена авторизация в учетной записи Яндекса.
  2. Приложению предоставлен доступ к микрофону устройства.
   Steps to Reproduce (Шаги воспроизведения):**
  1. Открыть приложение «Яндекс — с Алисой AI».
  2. Нажать на иконку голосового помощника Алисы.
  3. Активировать микрофон и произнести команду: «Включи музыку».
Expected Result (Ожидаемый результат):** Алиса озвучивает и выводит текст «Включаю». В чате отображается плеер с кнопкой «Слушать на Яндекс.Музыке» и элементами управления (Лайк, Дизлайк, Громче, Тише, Копировать, Поделиться).
Actual Result (Фактический результат):** Алиса возвращает дефолтный текстовый и голосовой отказ: «Прости, я не умею включать музыку...». Кнопка интеграции с Яндекс.Музыкой и элементы управления отсутствуют.
